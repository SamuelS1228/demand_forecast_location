# UIO Demand Forecast Streamlit App

This version includes demand by location.

## Outputs

- Demand by forecast year and product category
- Demand by location: CBSA and forecast year
- Demand by location/product: CBSA, forecast year, and product category
- Demand by age/product
- Age/product weighted rates
- Age/VMT bridge

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
